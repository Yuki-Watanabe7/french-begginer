# Product Overview

## アプリの目的

フランス語の動詞活用を、反復練習によって自然に身につけることを目的とした学習アプリです。
ルールを読んで覚えるのではなく、実際に手を動かして正誤フィードバックを繰り返すことで、活用形を体で覚えることを重視します。

## 対象ユーザー

- フランス語を独学で学んでいる初中級者
- スキマ時間（通勤・外出中）にスマホで練習したい人
- 動詞活用の定着に課題を感じている人

## 最初に重視する学習体験

1. **摩擦ゼロで問題が始まる** — アプリを開いたら即、問題が出る
2. **入力 → 判定 → 次へ** のループが快適に回ること
3. **スマホ片手操作** に最適化されたUI
4. **正誤がすぐ分かる** — 曖昧なフィードバックは学習を妨げる

## 将来的に追加したい機能候補

- **時制の拡張**: imparfait, futur simple, subjonctif など
- **動詞の拡張**: 不規則動詞・-er/-ir/-re 動詞の網羅
- **スコア記録**: 正解率・連続正解数の可視化
- **苦手動詞の優先出題**: 間違いが多い組み合わせを重点的に出す
- **ヒント機能**: 活用語尾のパターン表示
- **ユーザー認証**: 学習履歴をデバイスをまたいで保持
- **オフライン対応**: PWA化
